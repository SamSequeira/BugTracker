📁 src/db/queryBuilder.py Line 118 • Critical

SQL Injection vulnerability in user query builder

// Code snippet — src/db/queryBuilder.py:118
114 def getUserData(userId):
115 conn = getConnectbile()
116 cursor = conn.cursor()
117 query = "SELECT * FROM users WHERE id = " + userId
118 results = cursor.fetchall()
119 conn.close()
120 return results
What's wrong

User input is concatenated directly into SQL query without parameterization.

Suggested Fix (Diff)
- query = "SELECT * FROM users WHERE id = " + userId
+ query = "SELECT * FROM users WHERE id = %s"
+ cursor.execute(query, (userId,))
