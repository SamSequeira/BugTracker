EXISTING COMPONENT 2 BEHAVIOR:

Location: backend/app/services/llm_logic_reviewer/semantic_pipeline.py
Function: extract_functions(selected_file: SelectedFile) -> list[ExtractedFunction]
Lines: ~670-865

The implementation uses Python AST (Abstract Syntax Tree) for robust extraction.

EXTRACTS:
- Module-level functions (def func(): ...)
- Async functions (async def func(): ...)
- Class methods (class X: def method(): ...)
- Nested functions (def outer(): def inner(): ...)
- Functions nested in control flow (if/for/while/try/with blocks)

PRESERVES:
- Function name
- Class name (if method)
- Qualified name (ClassName.method_name or func_name)
- Start line and end line (from AST lineno/end_lineno)
- Complete source code (via _node_source helper)
- Parameters (including *args, **kwargs)
- is_async flag
- Decorators (e.g., @router.post("/path"))
- Called function names (via _calls helper)
- Module imports
- Class source (for methods)
- Module-level definitions referenced by the function

DOES NOT EXTRACT:
- Module-level constants (API_TIMEOUT = 30)
- Module-level assignments (DATABASE_URL = "...")
- Imports
- Comments
- Configuration

DATA STRUCTURE:
===============

@dataclass(frozen=True)
class ExtractedFunction:
    file_path: str                                      # Relative path to source file
    language: str                                       # "python"
    name: str                                          # Function name
    class_name: str | None                             # Class name if method, else None
    qualified_name: str                                # "ClassName.method" or "func"
    start_line: int                                    # AST lineno
    end_line: int                                      # AST end_lineno
    source: str                                        # Complete function source
    parameters: tuple[str, ...]                        # ("self", "amount", "*args", "**kwargs")
    is_async: bool                                     # True if async def
    decorators: tuple[str, ...]                        # ("@router.post('/path')",)
    called_names: tuple[str, ...]                      # Names of functions called
    imports: tuple[str, ...]                           # Module imports
    class_source: str | None                           # Full class source if method
    module_definitions: tuple[tuple[str, str, str], ...] # Module-level vars/classes

This structure is consumed by:
- Component 3 (build_context) - uses all fields for context construction
- Component 4-9 - use metadata for prompts, validation, deduplication
- reviewer.py - uses for pipeline orchestration
- Tests - use for verification

HELPER FUNCTIONS:
=================

1. _node_source(lines, node) -> str
   Extracts exact source code for an AST node using lineno/end_lineno

2. _calls(node) -> tuple[str, ...]
   Extracts syntactic function/method call names from AST

3. _target_names(target) -> list[str]
   Extracts variable names from assignment targets (handles tuple unpacking)

4. _module_level_definitions(tree, lines) -> list[tuple[str, str, str]]
   Extracts module-level variables and classes (not functions)

5. _referenced_module_names(node) -> set[str]
   Identifies names a function reads from module scope

6. _iter_nested_bodies(node) -> Iterable[list[ast.stmt]]
   Yields nested statement bodies for finding functions in control flow

ALGORITHM:
==========

1. Parse source file into AST (ast.parse)
2. Extract all imports from tree.body
3. Extract module-level definitions (vars, classes)
4. Recursively visit tree.body:
   a. If ClassDef: recurse into class body with class_name
   b. If FunctionDef/AsyncFunctionDef:
      - Extract all metadata
      - Create ExtractedFunction
      - Recurse into function body (for nested functions)
   c. If control flow (If/For/While/Try/With):
      - Recurse into all nested bodies
5. Sort results by (file_path, start_line, qualified_name)
6. Return list[ExtractedFunction]

ERROR HANDLING:
===============

Component 1 already validates syntax via ast.parse
Component 2 assumes valid Python from selected_file.path
If extraction fails, reviewer.py catches exceptions:

try:
    functions = extract_functions(selected_file)
except Exception as exc:
    logger.warning("Function extraction failed for %s: %s", ...)
    continue

Individual file failures do not crash the entire pipeline.
